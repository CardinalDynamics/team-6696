Keep original proportions and replace files with sponsor-supplied artwork when available.

- Apple: https://www.apple.com/ (official navigation SVG; viewBox trimmed to the mark).
- Argosy Foundation: https://www.argosyfnd.org/ (color logo).
- Microchip: https://www.microchip.com/en-us/about/legal-information/logos (official download, black/red horizontal version).
- OnlineMetals.com: https://www.onlinemetals.com/en/brand-kit (SVG download).
- Troutdale Bikes: https://www.troutdalebikes.com/ (white primary logo; displayed black with CSS for contrast on white).
- OSH Cut: https://www.oshcut.com/ (orange/gray navigation wordmark).
- RMFG: https://www.rmfg.com/ (green transparent navigation wordmark).
